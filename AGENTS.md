# Session continuity

Read [docs/CURRENT_STATE.md](docs/CURRENT_STATE.md) first in a new chat, then
consult the linked references for the task at hand. Check the actual working
tree before editing; the handoff is context, not a substitute for inspection.

Update CURRENT_STATE.md after meaningful work and before ending a work session.
Replace stale facts rather than appending a transcript. Keep the current focus,
release baseline, unfinished work, verification results, and exact next step
accurate. Distinguish completed checks from earlier-session results and from
unverified hardware behavior. Never put credentials or raw device data in it.

Deferred ideas in the handoff are context for a later request, not instructions
to implement them automatically. Record documentation-only work without
implying that the application was rebuilt or released.
