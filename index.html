Create or transform descriptions
Build an ordered numbered series, or preserve irregular values by capturing and rearranging named sections from existing descriptions.

            

              
Numbered series

              
Rename consecutive discovered ports, with the option to also apply one shared switching configuration.

              

                
                
                
                
                
              

              

                
                
                
              

              

                
Example description: 01_hw_ap_1

                
              

            


            

              
Transform existing descriptions

              
Match each selected port's current description, then reuse, remove, reorder, or surround any number of named sections.

              

                
                
              

              
Names in braces capture text; everything outside braces matches literally. Omit a name to remove that section, or reuse names in any order. Use {{ or }} for literal braces.

              
Select ports to preview description changes.

              

                Selected ports that do not match the current pattern are skipped.
